0. Базовые визуальные константы
   Основной цвет: #5757FF (Electric Blue). Используется для Primary-кнопок, активных состояний и выделения.
   Стиль: Современный темный интерфейс (Dark Theme), чистые линии, высокая контрастность текста.
   Эффекты: Glassmorphism (Backdrop Blur) для модальных окон, плавные переходы (200-300ms).
   Уведомления: Всплывающие уведомления об автосохранении (Toasts) в правом нижнем углу.

1. Landing (Hero-page)
   Структура: Одностраничный лендинг без стандартной шапки.
   Экран 1 (Hero):

- Background: Интерактивная CSS/Canvas анимация (графы, созвездия).
- Центральный блок: Логотип, Заголовок (H1), Подзаголовок (Body-L).
- Кнопки: \* Primary: "Начать" (редирект в Auth или Dashboard).
  Secondary (Outline): "Узнать больше" (якорная ссылка вниз).
  Экран 2 (Features): Layout «Зигзаг». Смена блоков: Текст + Описание (слева/справа) и Визуальный контент (справа/слева).
  Экран 3 (Footer CTA): Повтор кнопок действия, лаконичный футер с копирайтом и ссылками.

2. Глобальная шапка (Header)
   Появляется на всех страницах, кроме Hero-page.
   Левая часть: Логотип (кликабельный, ведет на Dashboard).
   Правая часть: Аватар пользователя (Dropdown):

- Настройки профиля.
- Тема (Светлая/Темная/Системная).
- Помощь/Справка.
- Выйти (Red accent).

3. Личный кабинет (Dashboard)
   Макет: Master-Detail (2 колонки).
   Правая область (Браузер проектов):

- Toolbar: Поиск, Сортировка, Переключатель вида (Сетка/Список).
- Карточка проекта: Изображение с затемняющим градиентом, название, описание.
- Состояние выделения: Обводка цветом #5757FF.
- Empty State: Иконка "Пустая планета" + кнопка "Создать новый".
  Левая область (Инспектор):
- Появляется при клике на проект.
- Данные: Название, Статус, Даты, Приватность.
- Команда: Список аватаров + кнопка добавления.
- Кнопки: "Открыть рабочее пространство" (Primary), "Удалить мир" (Red, снизу).
  Модальное окно создания: Поля: Название (default: "Без названия"), Описание, Загрузка обложки.

4. Настройки пользователя
   Макет: Дублирует структуру Dashboard (Список категорий слева — Форма справа).
   Секции меню: Общие, Внешний вид, Безопасность, Подписка, Danger Zone.
   Функционал: Смена аватара (Drag & Drop), изменение никнейма, управление сессиями, удаление аккаунта (с подтверждением).

5. Рабочее пространство (Editor)
   Макет: 3-х колоночный (IDE-style) со сворачиваемыми боковыми панелями.
   Левая панель (Навигация):

- (Создать), Поиск, Фильтры.
- Дерево файлов: папки и страницы (разные иконки для Markdown, Карт, Графов).
- Низ: Кнопка "Управление ролями" и Справка.
  Центральная область (Канвас):
- Автоматическая загрузка "Стартовой страницы".
- При отсутствии страниц — авто-раскрытие левой панели + подсказка.
  Правая панель (Инструменты): Контекстно-зависимая.
- Markdown: Инструменты форматирования, теги.
- Карта: Слои, инструменты рисования маркеров/зон, инспектор свойств маркера.
- Таймлайн: Список кадров (карт), установка дат/эпох для каждого кадра.
- Граф: Управление узлами (Персоны/События), настройка связей, привязка к статьям.

6. Адаптивность (Mobile UX)
   Dashboard: Только список плиток. При тапе — «шторка» (Bottom Sheet) с деталями и кнопкой входа.
   Настройки: Полноэкранный переход из списка категорий в настройки конкретной секции.
   Editor: Ограниченный функционал. Основной фокус на просмотре контента и редактировании Markdown. Редактор карт и графов скрыт или доступен в режиме «Read-only».
